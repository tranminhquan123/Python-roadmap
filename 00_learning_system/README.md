# Learning System

Thư mục này chứa hệ thống học tập cá nhân cho lộ trình Python → Data → DSA → Toán cho ML → Machine Learning → RAG.

Mục tiêu chính:

- Giảm tình trạng học xong rồi quên nhanh.
- Tập tự recall thay vì chỉ đọc lại.
- Ghi lại pattern giải bài.
- Ghi lại lỗi sai để không lặp lại.
- Theo dõi lịch ôn cách quãng.

---

## Các file chính

| File | Vai trò |
|---|---|
| `recall_log.md` | Ghi những gì tự nhớ lại được và những gì bị quên |
| `patterns.md` | Lưu các mẫu tư duy giải bài Python |
| `error_log.md` | Ghi lỗi sai, nguyên nhân và cách sửa |
| `review_schedule.md` | Theo dõi lịch ôn D+0, D+1, D+3, D+7, D+14, D+30 |

---

## Phương pháp học chính

### RSR-I

```text
Recall → Solve → Review → Interleave
```

Dùng để chống quên và biến kiến thức thành trí nhớ dài hạn.

### WEF-SE

```text
Worked Example Fading + Self-Explanation
```

Dùng để chuyển từ hiểu bài mẫu sang tự giải được bài tập.

---

## Quy trình mỗi buổi học

1. Recall bài cũ trong 10–15 phút.
2. Học hoặc làm bài mới.
3. Đóng tài liệu và viết lại ý chính từ trí nhớ.
4. Ghi pattern mới hoặc lỗi sai nếu có.
5. Cập nhật lịch ôn trong `review_schedule.md`.
